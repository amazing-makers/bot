# pdpbot ROADMAP

**시작일:** 2026-05-10

## Phase 1 — MVP: URL → 이미지 글자 제거 + 한국어 합성 (1-2주)

**가치:** 가장 시간 많이 쓰는 작업 (타오바오 이미지 1장 글자 지우고 번역) 5분 안에.

### 1.1 사이트 스크래핑 (`lib/scrapers/*.ts`)
- [ ] 쿠팡 — Playwright 로 상세페이지 이미지 추출 (대표 이미지 + 상세 이미지들)
- [ ] 타오바오 — 마찬가지 (다만 봇 차단 회피 필요, headers 조정)
- [ ] 1688 — 마찬가지
- [ ] 네이버 스마트스토어
- [ ] 아마존 (옵션)
- [ ] 일반 URL — meta og:image 폴백

### 1.2 이미지 텍스트 탐지 + 인페인팅
- [ ] GPT-4 Vision 으로 이미지 안 텍스트 위치 + 내용 추출
- [ ] FLUX 1.1 Pro Fill (Replicate) 로 마스크 영역 인페인팅
- [ ] 결과 PNG 보관 (R2 업로드, Phase 50 마케팅봇과 공유 가능)

### 1.3 번역 + 재합성
- [ ] Claude Opus 4.7 로 한국어 번역 (또는 사용자 직접 입력)
- [ ] 폰트 라이브러리 (한글 7-10개 — Pretendard, Noto Sans KR, GmarketSans 등)
- [ ] Sharp + canvas 로 텍스트를 인페인팅된 영역에 배치 (디자인 자동 — 색상·크기·정렬 추정)

### 1.4 UI 흐름
- [ ] 메인 페이지: URL 입력 → 진행 상황 표시 (스크래핑 → OCR → 인페인팅 → 번역)
- [ ] 결과 갤러리: before/after 비교, 개별 이미지 다운로드, 전체 ZIP 다운로드
- [ ] 텍스트 수정 모달: AI 번역 결과를 사용자가 수정 가능 (배치 수정 후 재합성)

### 1.5 데이터 모델
- [ ] `Product` — URL, 제목, 가격, 옵션
- [ ] `SourceImage` — 원본 이미지 (R2 URL)
- [ ] `TextRegion` — 이미지 안 텍스트 위치 (bbox + 원문 + 번역)
- [ ] `OutputImage` — 처리된 이미지 (인페인팅 + 번역 합성)

### Phase 1 완료 기준
- 사용자가 타오바오 URL 1개 입력 → 5분 안에 한국어 상세 이미지 5-10장 다운로드 가능

---

## Phase 2 — 상품·키워드 분석 (2-3주)

### 2.1 상품 자동 추출
- [ ] 제목·가격·옵션·카테고리·재고 자동 파싱
- [ ] 다른 사이트의 같은 상품 매칭 (이미지 검색 + 제목 유사도)

### 2.2 키워드 분석
- [ ] 네이버 데이터랩 / 쇼핑인사이트 API
- [ ] 검색량 + 경쟁 강도 + 추천 키워드
- [ ] Claude 로 SEO 친화적 제목 자동 추천

### 2.3 벤치마크 분석
- [ ] 같은 카테고리 상위 5개 상세페이지 스크린샷 → GPT-4 Vision 으로 구조 분석
- [ ] 어떤 섹션이 공통인가 (메인 비주얼, 사용 사례, 옵션 비교, 후기 등) → 추천 구조

---

## Phase 3 — 신규 상세페이지 통째로 자동 제작 (3-4주)

### 3.1 구조 + 카피라이팅 자동
- [ ] Phase 2 의 분석 결과 + 사용자 입력 (브랜드 톤, 타겟) → Claude 로 전체 상세페이지 outline 생성
- [ ] 섹션별 카피 (헤드라인 + 본문 + CTA)

### 3.2 이미지 자동 생성
- [ ] 섹션별 이미지 prompt 자동 생성
- [ ] FLUX 1.1 Pro 로 이미지 생성 (브랜드 컬러 + 상품 합성)
- [ ] 텍스트 오버레이 (DALL-E 3 또는 Sharp 합성)

### 3.3 레이아웃 합성
- [ ] 섹션을 PSD-스타일 layered 합성 (Sharp + SVG)
- [ ] PNG 한 장 또는 여러 장 (스크롤 상세페이지)
- [ ] 사용자 미리보기 + 부분 수정

---

## Phase 4 — 채널 자동 업로드 (1-2개월)

### 4.1 채널 어댑터
- [ ] **쿠팡 Wing API** — 가장 큰 시장. 셀러 가입 + API 토큰 필요.
- [ ] **네이버 스마트스토어 커머스 API**
- [ ] **11번가 OpenAPI**
- [ ] **카페24 / 메이크샵** (자체 쇼핑몰)

### 4.2 등록 흐름
- [ ] 사용자 채널 자격증명 등록 (마케팅봇 channel 모델 재사용)
- [ ] 상품 매핑 (제목, 가격, 옵션, 이미지 → 각 채널 schema)
- [ ] 일괄 등록 + 진행 상황 모니터링

---

## Phase 5 — 자동화 워크플로우 (이후)

### 5.1 정기 소싱
- [ ] 사용자가 키워드 등록 → 매일 새 상품 자동 발견
- [ ] 추천 상품 알림

### 5.2 일괄 자동
- [ ] CSV 또는 URL 목록 업로드 → 100개 상품 한 번에 상세페이지 생성 + 등록
